# 正文抓取下载扩展 · 安装与使用说明

扩展目录：`D:\Application\LESP · 辑微\extension`

```
extension\
├─ manifest.json        扩展清单（MV3）
├─ service_worker.js    后台：注入脚本、PDF 抓取
├─ content.js           正文提取器（在页面里运行）
├─ popup.html / popup.js / popup.css   点图标弹出的操作面板
├─ icons\               图标（复用 App 的仙鹤图标）
└─ 本文件
```

---

## 一、安装（加载已解压的扩展）

1. 打开 Chrome 或 Edge，地址栏输入 `chrome://extensions` 回车
   （Edge 会识别为 `edge://extensions`，一样能用）
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 选择文件夹：`D:\Application\LESP · 辑微\extension`
5. 装好后，点地址栏右边的**拼图图标**，把这个扩展**固定**到工具栏（以后一点就用）

> 改代码后：回到 `chrome://extensions`，点这个扩展卡片上的**刷新箭头**即可生效。

---

## 二、使用

1. 打开想保存的网页
2. 点工具栏上的扩展图标 → 弹出面板
3. 选择格式（默认 **PDF**）、可改文件名
4. 点 **「抓取并下载」**

面板会显示抓取结果：**字数 / 段落数 / 标题数 / 图片数**，以及需要注意的提示。

---

## 二之二、把抓取结果同步进「辑微」App（关键）

同步后，论文会自动出现在 App 的**「研究论文」**界面，不需要手工导文件。

**第 1 步：在 App 里拿两样东西**
1. 启动「辑微」→ 打开**设置页** → 找「浏览器扩展同步」卡片
2. 记下上面的 **本机端口**（默认 8791（App 为扩展专门开的固定端口））
3. 点 **「生成新口令」**，复制那串口令

**第 2 步：填进扩展**
1. 点扩展图标 → 展开最下面的 **「连接辑微 App 的设置」**
2. 填入端口和口令（会自动保存）
3. 点 **「测试连接」** —— 显示「已连上 LESP·辑微」就成功了

**第 3 步：用**
1. 打开论文页面 → 点扩展图标
2. 勾上 **「同步到辑微 App 的研究论文」**（默认已勾选）
3. 想连全文一起存，再勾 **「尝试下载全文」**
4. 点 **「抓取并下载」** → 提示「已同步到辑微」后，去 App 刷新即可看到

**数据去哪了**：论文写入 App 数据库；全文（PDF/CAJ）保存在 `data\files\cnki\` 目录，并作为附件挂在该条目下，在条目里能直接打开。

**同步失败怎么查**：
- 扩展面板会直接给出原因（连不上 App / 口令不对 / 没权限）
- App 设置页 → **「查看同步日志」** 能看到逐条记录，含失败原因

## 三、四种格式怎么选

| 格式 | 适合场景 | 说明 |
|---|---|---|
| **PDF** | 存档、打印、发给别人看 | 完整保留原页面排版（含背景图）；**需要临时开启调试通道** |
| HTML | 以后还要编辑、放进你的 App | 带一套阅读样式，浏览器打开即读，也能再打印成 PDF |
| Markdown | 做笔记、写综述 | 标题变 `#`，列表变 `-`，表格变 Markdown 表格 |
| TXT | 只要文字 | 段落之间空一行 |

## 四、关于 PDF 与「正在调试」横幅（重要）

Chrome **没有**给扩展提供静默打印接口（`chrome.tabs.print()` 只有 Firefox 有），
所以扩展要用浏览器的调试通道（`chrome.debugger` + `Page.printToPDF`）才能不出对话框直接存成 PDF。

**表现**：点 PDF 导出时，浏览器顶部会短暂出现一条 **「XXX 已开始调试此浏览器」** 的横幅。
**代码在拿到 PDF 后会立刻断开调试通道**，横幅随即消失（整个过程通常 1–3 秒）。

如果你不想看到它：
- 选 **HTML** 格式，下载后用浏览器打开，按 `Ctrl+P` → 目标选「另存为 PDF」
- 或者在面板里取消勾选「弹出另存为对话框」之外的 PDF 路径——即改用 HTML/TXT/MD

这个权限是**按需申请**的：你不用 PDF，扩展就永远不会碰调试通道。

## 五、权限说明（只申请了最小必要项）

| 权限 | 用途 |
|---|---|
| `activeTab` | 只对**你当前正在看、且刚点过图标**的页面生效，不常驻监控 |
| `downloads` | 把文件保存到本地 |
| `scripting` | 页面脚本没注入时，主动注入一次提取器 |
| `storage` | 记住你的格式与选项偏好 |
| `debugger`（可选） | **仅在你选择导出 PDF 时**才临时申请 |

**没有**声明 `host_permissions`、**没有**申请「读取所有网站数据」、也**没有**加载任何远程代码（完全遵守 MV3 的 CSP）。

## 六、常见问题

**Q：提示「没有找到可读的正文内容」**
- 内容可能是滚动到底才加载的 → 勾选 **「等待动态内容加载」** 再试
- 正文在 iframe 或内嵌 PDF 里 → 本扩展不处理（iframe 需要额外授权，属于更高风险权限，默认不做）

**Q：抓下来的内容混进了导航、广告文字**
- 该网页没用标准语义标签，扩展已退化为「整页提取」，面板会给出黄色提示
- 建议改用 **Markdown / TXT** 后手工删一段，或告诉我这个站点，我可以为它单独加提取规则

**Q：在知网上只能抓到摘要**
- 这是**预期行为**：知网正文是 CAJ/PDF 文件，不在网页 DOM 里。扩展会明确提示你这一条，不会假装抓到了全文
- 真正的知网全文要走下载链路（项目里的 `cnki_jobs` 队列）

**Q：PDF 导出失败 / 一直卡住**
- 页面含有大量动态脚本时可能超时，刷新页面重试
- 若浏览器策略禁止调试通道（部分公司管控的电脑），改用 HTML 格式

**Q：下载的文件名乱码或太怪**
- 文件名会自动去掉 Windows 不允许的字符（`\ / : * ? " < > |`），并限制在 80 字以内
- 同名的会**自动加序号**，不会覆盖已有文件

## 七、想缩小作用范围（可选）

默认 `manifest.json` 里的 `matches` 是 `http://*/*` 和 `https://*/*`（所有网页都能用）。
如果你只想在知网用，把那段改成：

```json
"matches": ["https://kns.cnki.net/*", "https://*.cnki.net/*"]
```

改完回到 `chrome://extensions` 点刷新即可。

## 八、全文下载：为什么有些篇自动下不到，怎么办

知网的下载按钮指向的是**下单页**（`bar.cnki.net/bar/download/order?id=...`），**不是文件**。
真正的文件地址是点击下载后由下单页内部**再产生一次**的，网页 DOM 里看不到。所以：

- 插件"自动下不到" = 它只看到下单页这一步（设计限制，不是故障）
- 你"手动能下" = 浏览器完成了第二步

### 两条解决办法

| 方式 | 步骤 |
|---|---|
| **A. 手动上传（随时可用）** | 自己点「PDF下载」→ 打开 App 该条目 → 「附件」页签 → 上传 |
| **B. 半自动（扩展已支持）** | ① 手动点一次「PDF下载」（浏览器真的下好一个文件）<br>② 扩展在后台**记住这次的真实文件地址**（30 分钟内有效）<br>③ 在 App 里**删除**该条目（会一并清除同步痕迹）<br>④ 回扩展勾「尝试下载全文」→ 点「抓取并下载」<br>→ 扩展用记住的真实地址取文件，新条目**自带 PDF 附件** |

> B 里第 ③ 步的删除是必需的：已有条目会被去重跳过，删除后重新抓取才能把全文一起带入（删除会清掉留档，因此能重新入库）。

### 判断当前有没有权限

看下载按钮的链接（右键 → 复制链接地址）：
- `bar.cnki.net/.../order` → **当前登录态对这篇没有下载权限**（只有付费/文献传递入口）
- `kns.cnki.net/.../download?...` → 有权限，插件可以直接下

若确认有权限却仍失败：检查页面地址里是否带 `captchaId=`（有即说明本次访问被风控标记过，退出重新登录、关掉标签页重进即可）。

## 九、全文获取：一次点击，自动入库

勾选「尝试下载全文」后：

1. **在知网点一次「PDF下载」**（就这一下手动操作，文件会正常下载到你的下载目录）
2. 扩展会自动捕获这次下载（30 分钟内有效）
3. 点「抓取并下载」→ 元数据入库 + 自动把刚下载的文件导入为附件

面板会显示「检测到你刚下载的全文（X 分钟前），将随元数据自动入库…」。

### 技术边界（为什么不能做到 0 次点击）

知网把下载的第二步（取真实文件）绑定在其下单页内部的私有会话流程中，
服务器对页面外的直接请求会返回“您尚未登录”（已在你的环境实测证实）。
不逆向该私有流程就无法做到零点击——逆向既脆弱也违反使用条款，故不做。

### 其他可用路径（备用）

- 路径 0/A：自动请求下载链接、浏览器下载引擎（部分文献可直接成功）
- 手动上传：App 条目「附件」页签随时可传
- 判断有无权限：右键下载按钮复制链接——bar.cnki.net/.../order 是下单页；kns.cnki.net/.../download 是直链
